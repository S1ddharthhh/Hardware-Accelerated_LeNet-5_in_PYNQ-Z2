# Hardware-Accelerated_LeNet-5_in_PYNQ-Z2
Hi everyone !! Here i have modified the vanila LeNet-5 model slightly and trained with the german traffic sign benchmark dataset. So by analysing the computation heavy layers i have designed an IP using Vitis HLS 2024.1 and implemented it in the PYNQ Z2 Platform. When compared to the arm processor on board i was able to gain upto 60x performance .
